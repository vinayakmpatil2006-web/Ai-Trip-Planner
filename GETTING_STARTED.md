## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Environment
```bash
cp .env.example .env
# Add your API keys to .env
```

### 3. Start Development
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
